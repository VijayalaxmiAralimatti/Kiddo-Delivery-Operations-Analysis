**Kiddo Delivery Operations Analysis:**

_**Technologies:**_ Microsoft Excel, Pivot Tables, Pivot Charts, Dashboard Design, Data Cleaning, Data Transformation, KPI Analysis, Statistical Analysis

**Project Overview:**
- Cleaned and transformed 8,717 raw delivery records into a validated dataset of 4,197 orders by removing duplicate and inconsistent records.
- Performed end-to-end operational analysis covering weekday vs. weekend demand, rider deployment & shift planning, ETA and delivery performance, rider delay analysis, peak-hour demand, delivery time, and ETA accuracy, and developed data-driven recommendations to improve delivery speed, rider utilization, customer experience, and operational efficiency.
- Built an Excel dashboard using Pivot Tables, Pivot Charts, KPI cards, formulas, and statistical analysis to visualize key operational metrics.
- Prepared a structured analytical report presenting business insights and actionable recommendations supported by charts, pivot tables, KPIs, and statistical analysis.

📌 **Note:**
- The original dataset and working Excel workbook are intentionally not included in this repository because they contain operational data and personally identifiable information (PII), such as rider names and contact details, provided as part of a technical assessment.
- To respect data privacy, ethical considerations, and responsible data handling practices, this repository includes the project report, dashboard screenshots, and supporting documentation. The analysis, methodology, and findings are based on the original dataset, while all sensitive information has been withheld from public distribution.
